# RoCreate

A Roblox development desktop workspace with AI chat, account and token tracking, local Hugging Face GGUF models, and integrated CLI terminals.

## Download

Open [Releases](https://github.com/YTStatikGaming/RoCreate-Releases/releases/latest) for the Windows x64 installer and release notes. The source repository is private; this repository holds public downloads. RoCreate is an early-access app and is not an official Roblox or AI-provider product.

Existing accounts, projects and history use the compatible ForgeDock data location. The installer may retain the legacy ForgeDock filename.
