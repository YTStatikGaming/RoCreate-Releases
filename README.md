# RoCreate

A Roblox development desktop workspace with AI chat, account and token tracking, local Hugging Face GGUF models, and integrated CLI terminals.

## Download

Get the Windows x64 installer from [the latest release](https://github.com/YTStatikGaming/RoCreate-Releases/releases/latest). This repository contains public downloads; application source is maintained privately. RoCreate is early access and is not an official Roblox or AI-provider product.

## Automatic updates

Fresh installations of **0.7.2 or later** automatically check this repository for updates. Downloads do not require a GitHub account.

Existing users should first update to **0.7.2** through their current local update folder or download the installer above. To switch to public updates, open **Settings → Updates → HTTPS release feed**, enable automatic checks, and save:

```text
https://github.com/YTStatikGaming/RoCreate-Releases/releases/latest/download/forgedock-update.json
```

The installer retains the legacy ForgeDock filename and data location to preserve existing projects, accounts and history. The app verifies update size and SHA-256 before installation.
